# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/06451d15-cf14-49fe-8090-b13234f3b397

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set `VITE_BACKEND_URL` in [.env.local](.env.local) to the LMSGEN backend URL. Keep `OPENAI_API_KEY` only on the backend.
3. Run the app:
   `npm run dev`
