# SCORM platform teal theme

The platform UI uses the existing SCORM AI reference palette:

- canvas: `#0A0F0E`
- surface: `#121A19`
- raised surface: `#17201F`
- primary teal: `#4FC9BF`
- strong teal: `#7BDCD3`

This theme is client/platform-only. It is not injected into generated learner SCORM packages.
